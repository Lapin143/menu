# Меню на 30 дней

Небольшое веб-приложение без сборки: меню на сегодня с заменой блюд, управление списком блюд и чек-лист покупок.

## Что внутри

- **Сегодня** — меню на текущий день (переключение по дням стрелками), кнопка «Заменить» показывает блюда того же типа из общего пула. Суп в субботу и воскресенье меняется сразу на два дня.
- **Блюда** — добавление и удаление блюд (завтраки, обеды, супы, ужины).
- **Покупки** — два списка: закупка на месяц и еженедельные покупки. Отмечаете купленное, затем вносите сумму чека. Чеки сохраняются в истории.
- **Настройки** — дата первого дня плана, экспорт и импорт `data.json`, сброс локальных правок.

## Где хранятся данные

- `data.json` — основная база: блюда, 30-дневный план, списки покупок и дата старта. Это файл, который лежит в репозитории.
- Правки блюд, замены, отметки и чеки хранятся в localStorage браузера. Они привязаны к конкретному браузеру и устройству.
- Чтобы правки попали в репозиторий: **Настройки → Экспорт data.json**, затем замените `data.json` в папке проекта и закоммитьте.

## Запуск локально

Откройте папку в терминале и запустите любой статический сервер, например:

```
python -m http.server 8000
```

Затем откройте http://localhost:8000. Открывать `index.html` двойным кликом нельзя: браузер не загрузит `data.json`.

## Публикация через GitHub Pages

1. Создайте репозиторий (например, `menu-app`) и загрузите в него файлы `index.html`, `style.css`, `app.js`, `data.json`, `README.md`.
2. В настройках репозитория: **Settings → Pages → Deploy from a branch → main / (root)**.
3. Через минуту приложение будет доступно по адресу `https://<ваш-логин>.github.io/menu-app/`.
